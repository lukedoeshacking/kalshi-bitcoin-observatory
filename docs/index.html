How to read the forecast

The model compares Coinbase spot with the contract threshold and scales the distance by the last hour’s one-minute volatility and time remaining. Kalshi settles using a 60-second BRTI average. Differences between Coinbase and BRTI can matter near the threshold. This experimental model has no verified accuracy or trading return.
